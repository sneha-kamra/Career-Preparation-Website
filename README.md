# Career Preparation Website

A web-based career and placement preparation platform designed to help students prepare for interviews, improve their skills, and get ready for job opportunities.

## Project Overview

The Career Preparation Website is designed to provide students and job seekers with useful resources for career development and placement preparation. The platform helps users prepare for interviews and improve their knowledge and job-readiness skills.

## Features

* Career and placement preparation resources
* Interview preparation materials
* User-friendly interface
* Organized career-related content
* Responsive web design
* Easy navigation between different sections
* Helpful resources for students and job seekers

## Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Database Management:** phpMyAdmin
* **Hosting:** Free Web Hosting

## Project Structure

* `admin/` – Contains admin-related files
* `images/` – Contains website images
* `pages/` – Contains different website pages
* `upload/` – Contains uploaded files
* `index.php` – Main entry page of the website

## 🌐 Live Website

The project is deployed on a free web hosting platform and can be accessed online.

**Live Demo:** https://careerprep.hstn.me

## Deployment

The website was deployed on a free web hosting platform with PHP and MySQL support. The required project files and database were configured on the hosting server to make the website accessible online.

## Project Purpose

This project was developed as an academic project to gain practical experience in:

* Web development
* PHP programming
* MySQL database connectivity
* Frontend development
* Career and placement-focused website development
* Website deployment and hosting
